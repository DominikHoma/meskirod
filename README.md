# Męski Ród — meskirod.pl

Landing page Centrum Wsparcia Mężczyzn zbudowana w Next.js 15.

## Uruchomienie

```bash
npm install
npm run dev
```

Strona dostępna pod adresem [http://localhost:3000](http://localhost:3000).

## Build produkcyjny

```bash
npm run build
npm start
```

## Struktura

- `src/content/` — treści (manifest, usługi, dane strony)
- `src/components/sections/` — sekcje landing page
- `public/logo.svg` — logo (przyłbica wojownicza)
